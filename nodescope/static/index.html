测试流程

  1. 解析订阅多种 UA 各拉一次合并去重，由 mihomo 为每个节点开本地端口。
  2. 探活按「探活并发」同时测 TCP / HTTP 延迟、落地地区、IP 类型和解锁情况。
  3. 测速探活通过的节点立即排队下载测速，「同时测速」控制并行数。
  4. 导出测完可导出可用节点（Clash YAML）或整张结果图。
